# Livraly Backend

Light backend scaffold for the Livraly delivery management system.

This folder is prepared for the larger backend build:

- Authentication and permissions
- Station colis lifecycle
- Scan events and history
- Livreur desk flow
- Caisse and finance
- Reclamation monitoring
- Admin settings

Suggested stack for tomorrow:

- Node.js + TypeScript
- PostgreSQL
- JWT auth
- WebSocket or SSE for live scan/caisse updates

Start point:

```bash
cd backend
npm install
npm run dev
```
